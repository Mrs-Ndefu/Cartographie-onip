Adressage de Foyers — ONIP

Application de terrain (version de test, build debug)

Télécharger l'APK
  1. Téléchargez le fichier depuis ce téléphone (même réseau Wi-Fi que le serveur).
  2. Ouvrez-le depuis les notifications ou le dossier Téléchargements.
  3. Si Android le demande, autorisez l'installation depuis cette source.
  4. Au premier lancement, saisissez l'adresse du serveur affichée par la personne qui vous l'a partagée.

Build de test — pas destiné à la production. Réinstallez cette APK après chaque mise à jour pour avoir la dernière version.
